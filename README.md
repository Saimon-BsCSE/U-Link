# 📖 About U-Link

**U-Link** is a student-focused social networking platform designed especially for university students to connect, communicate, and share experiences inside a campus community.

The platform allows students to create profiles using their university credentials, post updates, interact with others through reactions and comments, and stay connected with academic and social activities happening around campus.

Unlike traditional social media platforms, U-Link is built around the idea of creating a **safe, university-centered digital community** where students can collaborate, share knowledge, and engage with university life more meaningfully.

# 🎯 Purpose of the Project

The main goal of U-Link is to create a dedicated online space for students where they can:

* Connect with classmates and seniors
* Share academic resources
* Discuss university-related topics
* Post campus updates and events
* Build stronger student communities
* Encourage collaboration and communication

This project was inspired by the need for a social platform that feels more connected to university culture rather than general public social media.

# 🚀 Getting Started

If you want to run the project locally on your computer:

```bash
# Clone the repository
git clone https://github.com/saimon-bscse/U-Link.git

# Open the project folder
cd U-Link
```

Then simply open the `index.html` file in your browser.
